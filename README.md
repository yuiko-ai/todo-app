# ToDo管理アプリケーション

## 1. アプリの目的
- 個人で日常のタスク（やるべきこと）を管理し、完了・未完了を視覚的に把握できるようにする。
- 開発者として要件定義〜設計・実装・テストの一連の流れを習得する。

## 2. 要件定義
- **タスク登録**: タイトルを入力して新しいタスクを追加できる。
- **タスク一覧表示**: 登録されたタスクをリスト形式で表示する。
- **タスク編集・完了**: タスクの内容変更や、「完了」ステータスへの切り替えができる。
- **タスク削除**: 不要になったタスクを削除できる。

### 2.3 非機能要件
- データはデータベース（DB）に保存し、アプリ再起動後も保持されること。
- PCのWebブラウザで快適に操作できること。

## 3. 画面構成（予定）
